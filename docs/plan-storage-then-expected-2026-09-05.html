1 · Why one plan, and why storage goes first

Phase 8 needs a base named by its content and kept while anything references it. That is exactly what storage A builds for every derived file. Building A3 first would write a second, hand-refcounted store into a directory T11 removes a week later; building A first makes A3 three lines. So: storage A in full, then phase 8 rebased on it. The only phase-8 tasks that could run earlier are A1 and A2 (they touch the capture, not the fold) — the plan keeps them in order anyway, one tree, one harvest at a time.
