gal-game feellow–midhigh at the moment that mattershighest, everywhere
honesty ruleskept as-iskept (the scene is a skin over the same Resolve)kept in logic; every visual cue must be re-proven
Recommendation: B. The human wants all three purposes — delight, behaviour, teaching — and A is too quiet to change behaviour: nobody clears a queue because a muted portrait blinked. C pays for a whole second design system before one conflict is settled. B spends the gal-game budget exactly where the product's one real decision is (R3, "the tool never picks"), keeps the paper board as the honest surface for everything measured, and the "throughout" touches ride on A's treatment. Failure mode, said first: B lives or dies on sprite quality and on the transition; if the generated cast looks like this sheet in a year, it holds. Build A's strip as the floor and B's scene on top; keep C as a theme option, not a direction.

References the panel leans on

  • Character inside a decision. Clippy — mandatory and interruptive, the canonical backfire. Notion's AI face (eyebrows while thinking, falls apart on error) — a state indicator, the pattern to copy. No dev tool with a real dialogue-choice decision UI was found; this is new ground.
  • Companions. vscode-pets asks nothing and is loved; code-tamagotchi pays XP per deleted line and is a metric-gaming vector. Duolingo's Duo carries loss-aversion in character; it works because the unit is daily and small.
  • Visual novel × real engineering. Code Romantic (VN + real C# puzzles); paiza's コードガールこれくしょん (heroine + gacha over coding drills, 4M+ plays); TwilioQuest (RPG missions over your real terminal); Zachtronics TIS-100 / SHENZHEN I/O.
  • Honest scalars. Stryker's mutation score (killed mutants — proven/unproven's cousin); Codewars kyu (rank ≠ activity); Advent of Code stars — and AoC removed its global leaderboard after abuse.
  • Backfires. GitHub's YOLO / Pull Shark badges reward skipping review and PR volume; Stack Overflow reputation grew voting rings; the "Achievement Unlocked" DevOps badge study (arXiv 2208.05860) — the testing badge cut commits; novelty effect drops after ~4 weeks (Rodrigues 2022).
